# ท่อ PVC มอก. 17 คืออะไร ต่างจากท่อไม่มี มอก. ยังไง (มุมงานโครงการ)

**ท่อ PVC มอก. คือท่อที่ผ่านมาตรฐาน มอก. 17-2561 ซึ่งควบคุมท่อพีวีซีแข็ง (PVC-U) สำหรับน้ำดื่ม กำหนดสีฟ้า ขนาด ความหนาผนัง แรงดันตาม class วัสดุปลอดโลหะหนัก และการพิมพ์เครื่องหมายบนท่อ สำหรับงานโครงการมันสำคัญเพราะใช้ผ่านสเปก ตรวจรับงาน และการันตีความปลอดภัยของระบบน้ำ**

สำหรับงานบ้านหลังเดียว หลายคนอาจไม่ทันคิดเรื่อง มอก. แต่พอเป็นงานโครงการ ท่อ PVC มอก. ไม่ใช่แค่ "ของดีกว่า" แต่มันคือเงื่อนไขผ่าน/ไม่ผ่านของงาน บทความนี้เจาะมุมมาตรฐานกับงานโครงการโดยเฉพาะ ไม่ลงตารางขนาดละเอียด (อันนั้นแยกไว้อีกบทความ)

## มอก. 17-2561 คืออะไร ครอบคลุมอะไรบ้าง

มอก. 17-2561 คือมาตรฐานผลิตภัณฑ์อุตสาหกรรมของ "ท่อพีวีซีแข็ง (PVC-U) สำหรับใช้เป็นท่อน้ำดื่ม" เป็นฉบับที่ปรับปรุงใหม่ล่าสุด และเป็นมาตรฐานบังคับ แปลว่าผู้ผลิตในไทยต้องผ่านมาตรฐานนี้ก่อนจึงจะขายท่อน้ำดีได้

สิ่งที่มาตรฐานนี้ควบคุม:

- **สี** — ท่อน้ำดีต้องเป็น "สีฟ้า" เพื่อแยกจากท่อร้อยสายไฟสีเทา ลดการหยิบผิด
- **ขนาดและความหนาผนัง** — คุมเส้นผ่านศูนย์กลางภายนอก (OD) และความหนาให้อยู่ในค่ายอมรับ
- **ชั้นคุณภาพ (class)** — แบ่งตามแรงดันใช้งานที่ท่อรับได้
- **คุณสมบัติวัสดุ** — จุดเด่นของฉบับ 2561 คือคุมการปนเปื้อนของโลหะหนัก เช่น ตะกั่ว เพราะเป็นท่อที่สัมผัสน้ำดื่มโดยตรง
- **การทำเครื่องหมาย** — บังคับพิมพ์ข้อมูลระบุตัวตนบนท่อตลอดความยาว

พูดง่ายๆ คือ มอก. 17-2561 การันตีว่าท่อเส้นนั้นได้ขนาดตรงสเปก รับแรงดันได้จริงตาม class ที่เขียน และปลอดภัยพอจะใช้กับน้ำดื่ม

## ทำไม ท่อ PVC มอก. ถึงสำคัญกับงานโครงการ

งานโครงการต่างจากงานบ้านตรงที่ทุกอย่างต้อง "พิสูจน์ได้บนกระดาษ" ไม่ใช่แค่ทำเสร็จแล้วน้ำไหล เหตุผลหลักมี 3 ข้อ

**1. ผ่านสเปก** — TOR หรือสัญญางานโครงการ (โดยเฉพาะงานราชการและดีเวลลอปเปอร์รายใหญ่อย่าง AP, Sansiri, Pruksa) มักระบุตรงๆ ว่าท่อประปาต้องได้ มอก. และบางทีระบุยี่ห้อ class มาเลย ถ้าเอาของไม่ตรงเข้าไปคือผิดสัญญาตั้งแต่ต้น

**2. ตรวจรับงาน** — ผู้ควบคุมงาน (CM/ผู้คุมงาน) มีสิทธิ์ขอดูใบรับรอง มอก. และเดินดูตัวพิมพ์บนท่อหน้างาน ถ้าไม่มี มอก. หรือเอกสารไม่ครบ งวดงานนั้นอาจไม่ผ่าน เบิกเงินไม่ได้

**3. ความปลอดภัยและความรับผิด** — ระบบน้ำในอาคารมีแรงดัน ถ้าท่อแตกหลังส่งมอบ ผู้รับเหมาคือคนรับผิดชอบ ท่อได้มาตรฐานช่วยลดความเสี่ยงตรงนี้ และมีหลักฐานว่าเลือกวัสดุถูกต้องแล้ว

## ท่อ PVC มอก. vs ท่อไม่มี มอก. ต่างกันตรงไหน

| หัวข้อ | ท่อ PVC มี มอก. 17-2561 | ท่อ PVC ไม่มี มอก. |
|---|---|---|
| ความหนาผนัง | คงที่ ตรงตามค่ามาตรฐาน | บางไม่สม่ำเสมอ บางล็อตบางกว่าที่ควร |
| แรงดันตาม class | รับได้จริงตามที่พิมพ์ | อ้าง class แต่รับได้ไม่ถึง เสี่ยงแตก |
| วัสดุ/ความปลอดภัย | คุมโลหะหนัก ใช้กับน้ำดื่มได้ | ไม่มีการรับรอง อาจมีสารปนเปื้อน |
| เอกสารรับรอง | มีใบอนุญาต/ใบรับรองใช้ตรวจรับได้ | ไม่มี ยื่นตรวจรับงานไม่ได้ |
| ใช้กับงานโครงการ | ผ่านสเปก | มักถูกปฏิเสธ ต้องรื้อเปลี่ยน |
| ต้นทุนรวมระยะยาว | คุ้มกว่า ปัญหาน้อย | ถูกหน้างาน แต่เสี่ยงบานปลาย |

จะเห็นว่าราคาต่อเส้นของท่อไม่มี มอก. อาจถูกกว่านิดหน่อย แต่พอคิดรวมความเสี่ยงตรวจรับไม่ผ่านกับค่ารื้อซ่อม มันไม่คุ้มเลยสำหรับงานโครงการ

## ดูสัญลักษณ์ มอก. บนท่อ PVC ยังไง

วิธีเช็คหน้างานง่ายสุดคือดูตัวพิมพ์บนผิวท่อ ท่อได้มาตรฐานจะพิมพ์ข้อมูลเป็นแถวยาวตลอดเส้น ประกอบด้วย

- ยี่ห้อผู้ผลิต (เช่น SCG ตราช้าง หรือ ตราไทย)
- ขนาดท่อ (นิ้ว/มม.)
- ชั้นคุณภาพ class (เช่น 8.5, 13.5)
- เลขมาตรฐาน **มอก. 17-2561**
- เลขที่ใบอนุญาตทำผลิตภัณฑ์อุตสาหกรรม

จุดสังเกตเพิ่มเติม: ท่อน้ำดีต้องเป็นสีฟ้า ตัวพิมพ์คมชัด อ่านออกตลอดเส้น ถ้าเจอท่อสีแปลกๆ ตัวพิมพ์เลอะ อ่านไม่ออก ไม่มีเลข มอก. หรือราคาถูกผิดปกติ ให้สงสัยไว้ก่อนแล้วขอใบรับรองจากผู้ขาย

## ความเสี่ยงของท่อไม่ได้มาตรฐาน

ท่อไม่มี มอก. ที่เจอบ่อยคือผนังบางกว่าที่ควร เพื่อลดต้นทุนเนื้อวัสดุ ผลที่ตามมาหน้างานคือ

- **แตกร้าวตอนรับแรงดันปั๊ม** — พอเจอ water hammer ตอนปั๊มตัดต่อ ท่อบางแตกง่ายกว่ามาก
- **อายุใช้งานสั้น** — เปราะเร็ว โดยเฉพาะจุดที่โดนแดดหรือฝังในโครงสร้าง ซ่อมทีหลังยากและแพง
- **ปนเปื้อนน้ำ** — วัสดุที่ไม่คุมโลหะหนักไม่เหมาะกับระบบน้ำดื่ม
- **ตรวจรับไม่ผ่าน** — ไม่มีเอกสารยืนยัน งานสะดุด เบิกงวดไม่ได้

สำหรับงานโครงการ ข้อสุดท้ายเจ็บสุด เพราะกระทบทั้งเวลาและกระแสเงินสด

## ชั้นคุณภาพ (class) ตาม มอก. โดยย่อ

ภายใต้ มอก. 17-2561 ท่อสีฟ้าแบ่ง class ตามแรงดันใช้งานสูงสุด class 5 รับ 5 บาร์ class 8.5 รับ 8.5 บาร์ และ class 13.5 รับ 13.5 บาร์ ในขนาดเรียกเดียวกัน OD เท่ากันหมด ต่างกันที่ความหนาผนัง ยิ่ง class สูงผนังยิ่งหนา

งานโครงการส่วนใหญ่ท่อเมนและงานฝังดินนิยม class 13.5 ส่วนท่อแยกจุดใช้น้ำมัก class 8.5 รายละเอียดขนาดครบทุกนิ้วและตาราง class เต็มดูได้ที่ [ตารางขนาดท่อ PVC + class](/blog/pvc-pipe-size-chart) และถ้าอยากรู้ว่าท่อฟ้า เทา เหลือง ต่างกันยังไง อ่าน [ท่อ PVC มีกี่ประเภท](/blog/pvc-pipe-types)

## เตรียมเอกสาร/ใบรับรองสำหรับงานโครงการ

เวลาส่งงานโครงการ ตัวท่อได้ มอก. อย่างเดียวไม่พอ ต้องมีกระดาษยืนยันด้วย เตรียมชุดนี้ไว้จะราบรื่น

- **สำเนาใบอนุญาต มอก.** ของผู้ผลิตท่อ
- **ใบรับรอง/certificate** ของล็อตหรือรุ่นสินค้าที่ส่ง
- **ใบส่งของ/ใบกำกับภาษี** ที่ระบุยี่ห้อ ขนาด class ให้ตรงกับสเปกในสัญญา
- **ตัวอย่างท่อพร้อมตัวพิมพ์** ให้ผู้คุมงานตรวจเทียบได้

เคล็ดลับ: สั่งของจากร้านที่ออกเอกสารครบตั้งแต่แรกได้ จะประหยัดเวลาไล่ขอทีหลังมาก และช่วยให้วัสดุที่ส่งตรงกับที่เขียนในสเปกเป๊ะ เรื่องนี้เราลงรายละเอียดไว้ที่ [จัดหาวัสดุงานระบบสำหรับโครงการ](/blog/project-material-supply)

## คำถามที่พบบ่อย (FAQ)

**1. มอก. 17 ท่อ PVC คืออะไร**
มอก. 17-2561 คือมาตรฐานท่อพีวีซีแข็ง (PVC-U) สำหรับน้ำดื่ม กำหนดให้ท่อน้ำดีเป็นสีฟ้า คุมขนาด ความหนา แรงดันตาม class โลหะหนัก และการพิมพ์เครื่องหมาย เป็นมาตรฐานบังคับที่ผู้ผลิตต้องผ่าน

**2. ท่อ PVC ไม่มี มอก. ใช้กับงานโครงการได้ไหม**
โดยทั่วไปไม่ได้ เพราะสเปกงานโครงการและงานราชการระบุให้ใช้ท่อได้ มอก. และต้องแนบใบรับรองตอนตรวจรับ ถ้าใช้ของไม่มี มอก. อาจถูกปฏิเสธและต้องรื้อเปลี่ยนเอง

**3. ดูสัญลักษณ์ มอก. บนท่อ PVC ตรงไหน**
ดูตัวพิมพ์บนตัวท่อตลอดความยาว จะมียี่ห้อ ขนาด class เลข มอก. 17-2561 และเลขที่ใบอนุญาต ท่อน้ำดีต้องเป็นสีฟ้า ถ้าตัวพิมพ์อ่านไม่ออกหรือไม่มีเลข มอก. ให้สงสัยไว้ก่อน

**4. ท่อ PVC มอก. กับไม่มี มอก. ต่างกันยังไง**
ท่อมี มอก. คุมขนาด ความหนา แรงดันตรง class วัสดุปลอดโลหะหนัก มีใบรับรองใช้ตรวจรับได้ ส่วนท่อไม่มี มอก. มักผนังบาง รับแรงดันไม่ตรงสเปก แตกง่าย และยื่นตรวจรับไม่ได้

**5. งานโครงการต้องเตรียมเอกสารอะไรเรื่องท่อ PVC**
เตรียมสำเนาใบอนุญาต มอก. ของผู้ผลิต ใบรับรองของล็อตสินค้า และใบส่งของที่ระบุยี่ห้อ ขนาด class ให้ตรงกับสเปกในสัญญา เพื่อใช้ยื่นตอนตรวจรับงาน

## สรุป เลือกท่อ PVC ได้มาตรฐานให้จบงานโครงการ

สำหรับงานโครงการ ท่อ PVC มอก. 17-2561 ไม่ใช่ทางเลือก แต่เป็นเงื่อนไขผ่านงาน ตั้งแต่ผ่านสเปก ตรวจรับ ไปจนถึงความปลอดภัยและเอกสารรับรอง เลือกท่อสีฟ้าได้มาตรฐาน ดูตัวพิมพ์ให้ครบ แล้วเก็บใบรับรองไว้ตั้งแต่แรก
