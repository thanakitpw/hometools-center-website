# เลือกวัสดุงานระบบ โครงการ ให้ผ่านสเปกต้องดูอะไรบ้าง

**การเลือกวัสดุงานระบบให้ผ่านสเปกโครงการ ต้องเริ่มจากอ่าน spec ให้ขาดว่ากำหนดแบรนด์ตายตัวหรือเปิดช่อง "หรือเทียบเท่า" จากนั้นเลือกของที่มี มอก. ตรงข้อกำหนด เตรียมเอกสาร submittal และใบรับรองให้ครบ พร้อมวางแผน lead time และจำนวนให้ทันงาน เท่านี้ก็ลดโอกาสถูกตีกลับได้มาก**

สำหรับผู้รับเหมาและฝ่ายจัดซื้อ การจัดซื้อวัสดุงานระบบไม่ใช่แค่หาของถูกที่สุด แต่คือหาของที่ "ผ่านการอนุมัติ" จากที่ปรึกษาโครงการหรือ Consult ให้ได้ก่อน บทความนี้จะพาไล่ตั้งแต่วิธีอ่าน spec เกณฑ์การเลือก การเทียบของเทียบเท่า ไปจนถึงเอกสารที่ต้องเตรียม และข้อผิดพลาดที่ทำให้ของถูกตีกลับบ่อยที่สุด

---

## อ่าน spec โครงการให้ขาด ก่อนสั่งของ

ก่อนจะเลือกวัสดุ ต้องเข้าใจก่อนว่า spec หรือข้อกำหนดของโครงการเขียนไว้แบบไหน เพราะเงื่อนไขต่างกันคือกติกาคนละแบบ

### แบรนด์ที่กำหนดตายตัว (Proprietary Spec)

บาง spec ระบุยี่ห้อและรุ่นชัดเจน ไม่มีคำว่าเทียบเท่า กรณีนี้ต้องใช้ตามนั้นเป๊ะ ๆ การเปลี่ยนยี่ห้อเองมักถูกตีกลับทันที ถ้าอยากเปลี่ยนต้องทำเรื่องขออนุมัติเป็นทางการก่อน

### "หรือเทียบเท่า" (Or Equal / Or Approved Equal)

เป็นข้อความที่พบบ่อยสุด เช่น "ท่อ PVC ตราช้าง หรือเทียบเท่า" หมายความว่าเปิดช่องให้เสนอยี่ห้ออื่นที่มีคุณสมบัติ **เทียบเท่าหรือดีกว่า** ได้ แต่ต้องผ่านการอนุมัติจากผู้ออกแบบหรือ Consult ก่อนเสมอ ไม่ใช่เปลี่ยนได้เอง

### มาตรฐานที่ต้องมี (Performance Spec)

บาง spec ไม่ระบุยี่ห้อ แต่ระบุมาตรฐานที่ต้องผ่าน เช่น "ท่อ PVC ตาม มอก. 17-2561 ชั้นคุณภาพ 8.5" หรือ "วาล์วทองเหลืองตามมาตรฐาน วสท." กรณีนี้เลือกยี่ห้อไหนก็ได้ที่มีเอกสารรับรองตรงมาตรฐานนั้น

> เคล็ดลับ: ไฮไลต์คำสำคัญใน spec ทุกจุด — ยี่ห้อ, รุ่น, เลข มอก., ชั้นคุณภาพ (class), ขนาด, และคำว่า "หรือเทียบเท่า" — ก่อนออกใบสั่งซื้อทุกครั้ง

---

## เกณฑ์เลือกวัสดุงานระบบสำหรับโครงการ

เมื่ออ่าน spec ขาดแล้ว การเลือกวัสดุจริงต้องชั่งน้ำหนักหลายด้าน ไม่ใช่แค่ราคา ใช้ตารางนี้เป็นเช็คลิสต์ได้เลย

| เกณฑ์ | สิ่งที่ต้องตรวจ | ทำไมสำคัญ |
|---|---|---|
| ตรงมาตรฐาน | มี มอก. / มาตรฐานตรงที่ spec กำหนด มีใบรับรองยืนยัน | ข้อแรกที่ Consult ตรวจ ถ้าไม่ผ่านคือจบ |
| คุณภาพ | ชั้นคุณภาพ (class) ความหนา วัสดุ ตรงหรือดีกว่าที่กำหนด | ป้องกันปัญหาหน้างานและการรับประกัน |
| ราคา | ราคาจริง สมเหตุผลกับเกรด ไม่ใช่ถูกจนน่าสงสัย | คุมต้นทุนโครงการโดยไม่เสียคุณภาพ |
| ของพร้อมส่ง | มีสต็อก จำนวนพอ ส่งได้ตามแผนงาน | กันงานสะดุดเพราะของขาด |
| บริการหลังการขาย | รับประกัน เปลี่ยน/เคลม มีอะไหล่ต่อเนื่อง | โครงการใช้เวลาหลายเดือนถึงหลายปี |

จุดที่ฝ่ายจัดซื้อพลาดบ่อยคือโฟกัสราคาถูกที่สุดอย่างเดียว แล้วลืมว่าถ้าของไม่ผ่านสเปกหรือส่งไม่ทัน ต้นทุนที่ตามมาจากงานล่าช้าแพงกว่าส่วนต่างราคาหลายเท่า

---

## เทียบวัสดุ "เทียบเท่า" ให้ผ่านการอนุมัติ

หัวใจของงาน B2B คือการเสนอของเทียบเท่าให้ Consult อนุมัติได้จริง ไม่ใช่แค่บอกว่า "ของนี้ก็เหมือนกัน"

### ทำตารางเทียบคุณสมบัติ (Comparison Sheet)

วางของที่ spec กำหนดไว้คู่กับของที่จะเสนอ แล้วเทียบทีละหัวข้อ — มาตรฐาน, วัสดุ, ชั้นคุณภาพ, ขนาด, แรงดันใช้งาน, การรับประกัน ให้เห็นชัดว่าเทียบเท่าหรือดีกว่าตรงไหน

### แนบเอกสารรับรองให้ครบ

คำพูดอย่างเดียวไม่พอ ต้องมีใบรับรอง มอก., Data Sheet, และผลทดสอบ (Test Report) ประกอบ ยิ่งเอกสารครบ Consult ยิ่งอนุมัติเร็ว

### เสนอตั้งแต่เนิ่น ๆ

อย่ารอจนใกล้ต้องใช้ของ เพราะการอนุมัติของเทียบเท่าใช้เวลา ถ้าถูกปฏิเสธจะได้มีเวลาหาทางเลือกอื่นทัน

---

## จัดการ lead time และจำนวนให้ทันงาน

ของผ่านสเปกแล้วแต่มาไม่ทัน ก็ทำให้งานสะดุดได้ การจัดซื้อวัสดุงานระบบที่ดีต้องคุมเวลาและจำนวนควบคู่กัน

- **เช็ค lead time จริงก่อนรับปาก** — สินค้าบางตัว โดยเฉพาะของสั่งผลิตหรือขนาดพิเศษ ใช้เวลานานกว่าปกติ
- **สั่งเผื่อเปอร์เซ็นต์เสียหาย** — งานท่อ งานเดินระบบ มักมีเศษตัดและของเสียหน้างาน เผื่อไว้ตามชนิดงาน
- **ทยอยส่งตามงวดงาน** — ของบางอย่างไม่ควรกองหน้างานนานเพราะเสี่ยงชำรุดหรือหาย วางแผนส่งเป็นล็อตตามความคืบหน้า
- **ล็อกราคาและจำนวนกับซัพพลายเออร์** — โครงการยาวหลายเดือน ควรมีข้อตกลงราคาชัดเจนกันของขึ้นราคาระหว่างทาง

การเลือกร้านที่มีของพร้อมส่งและสต็อกลึกช่วยลดความเสี่ยงเรื่องนี้ได้มาก โดยเฉพาะเมื่อหน้างานต้องการของด่วน

---

## เตรียมเอกสาร submittal และใบรับรอง

Submittal คือชุดเอกสารที่ยื่นให้ Consult อนุมัติก่อนสั่งของเข้าหน้างาน เป็นขั้นตอนที่ห้ามข้าม ชุดเอกสารมาตรฐานควรมี

| เอกสาร | รายละเอียด |
|---|---|
| Material Submittal Form | ฟอร์มสรุปวัสดุที่เสนอ อ้าง spec ข้อที่เกี่ยวข้อง |
| ใบรับรอง มอก. | ยืนยันว่าสินค้าได้มาตรฐานตามที่กำหนด |
| Catalog / Data Sheet | ข้อมูลทางเทคนิคจากผู้ผลิต |
| Test Report | ผลทดสอบคุณสมบัติ (ถ้า spec ต้องการ) |
| Comparison Sheet | ตารางเทียบ (กรณีเสนอของเทียบเท่า) |
| ตัวอย่างสินค้า (Sample) | บางโครงการขอตัวอย่างจริงประกอบ |

ยื่นครบตั้งแต่รอบแรก จะช่วยให้ผ่านเร็วโดยไม่ต้องส่งกลับไปกลับมาหลายรอบ

---

## ข้อผิดพลาดที่ทำให้วัสดุถูกตีกลับ

รวมจุดพลาดที่เจอบ่อยหน้างานโครงการ เลี่ยงได้ตั้งแต่ต้นจะประหยัดเวลามาก

- **เปลี่ยนยี่ห้อเองโดยไม่ขออนุมัติ** — แม้ของดีกว่า ถ้าไม่ผ่าน submittal ก็ถูกตีกลับ
- **เอกสารไม่ครบ/ไม่ตรงรุ่น** — ใบรับรองเป็นคนละรุ่นกับของที่ส่งจริง เป็นเหตุตีกลับยอดฮิต
- **อ่าน spec ไม่ครบ** — พลาดชั้นคุณภาพหรือมาตรฐานย่อยที่ระบุไว้
- **ส่งของก่อนอนุมัติ submittal** — ของเข้าหน้างานก่อนได้ไฟเขียว เสี่ยงต้องขนกลับ
- **ของจริงไม่ตรงตัวอย่างที่อนุมัติ** — ล็อตที่ส่งต้องตรงกับที่ผ่านการอนุมัติทุกจุด

## สรุป

## คำถามที่พบบ่อย (FAQ)

**Q: "หรือเทียบเท่า" ใน spec หมายความว่าเปลี่ยนยี่ห้อได้เลยใช่ไหม?**
A: ไม่ใช่ คำว่า "หรือเทียบเท่า" เปิดช่องให้เสนอยี่ห้ออื่นที่มีคุณสมบัติเทียบเท่าหรือดีกว่าได้ก็จริง แต่ต้องผ่านการอนุมัติจากผู้ออกแบบหรือ Consult ก่อนเสมอ การเปลี่ยนเองโดยไม่ขออนุมัติมักถูกตีกลับ

**Q: ต้องเตรียมเอกสารอะไรบ้างสำหรับ submittal?**
A: ชุดมาตรฐานประกอบด้วยฟอร์ม Material Submittal, ใบรับรอง มอก., Catalog หรือ Data Sheet, Test Report (ถ้ากำหนด), Comparison Sheet กรณีเสนอของเทียบเท่า และตัวอย่างสินค้าในบางโครงการ ยื่นครบตั้งแต่รอบแรกช่วยให้ผ่านเร็วขึ้น

**Q: ทำไมของราคาถูกสุดถึงไม่ควรเป็นเกณฑ์เดียวในการเลือก?**
A: เพราะถ้าของไม่ผ่านสเปกหรือส่งไม่ทัน ต้นทุนจากงานล่าช้าและการหาของใหม่มักแพงกว่าส่วนต่างราคาหลายเท่า ควรชั่งน้ำหนักคุณภาพ มาตรฐาน ของพร้อมส่ง และบริการหลังการขายควบคู่ไปด้วย

**Q: สาเหตุที่วัสดุถูกตีกลับบ่อยที่สุดคืออะไร?**
A: ที่พบบ่อยคือเปลี่ยนยี่ห้อเองโดยไม่ขออนุมัติ เอกสารรับรองไม่ครบหรือเป็นคนละรุ่นกับของจริง อ่าน spec ไม่ครบจนพลาดชั้นคุณภาพ และส่งของเข้าหน้างานก่อน submittal ได้รับอนุมัติ

**Q: ควรวางแผน lead time วัสดุงานระบบอย่างไร?**
A: เช็คเวลาสั่งจริงกับซัพพลายเออร์ก่อนรับปากงาน โดยเฉพาะของสั่งผลิตหรือขนาดพิเศษ สั่งเผื่อเปอร์เซ็นต์เสียหาย ทยอยส่งตามงวดงานเพื่อลดความเสี่ยงของกองหน้างาน และล็อกราคากับจำนวนไว้ล่วงหน้าสำหรับโครงการที่ใช้เวลานาน
