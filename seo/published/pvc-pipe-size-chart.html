ตารางขนาดท่อ PVC มาตรฐาน มอก. 17-2561 แบ่งตามเส้นผ่านศูนย์กลางภายนอก (OD) ตั้งแต่ 1/2 นิ้ว (OD 22 มม.) ไปจนถึง 16 นิ้ว (OD 420 มม.) และแบ่งชั้นคุณภาพเป็น class 5, 8.5 และ 13.5 ซึ่งหมายถึงแรงดันใช้งานสูงสุด 5, 8.5 และ 13.5 บาร์ตามลำดับ ยิ่งเลข class สูง ผนังท่อยิ่งหนาและรับแรงดันได้มากขึ้น

เวลาไปหน้าร้านแล้วบอกว่า "เอาท่อ 6 หุน" คนขายรู้ทันทีว่าหมายถึงอะไร แต่พอต้องสั่งงานโครงการ เขียนสเปก หรือเลือก class ให้ถูกกับระบบ ตัวเลขพวกนี้เริ่มสับสน บทความนี้เราจัดตารางขนาดท่อ PVC ให้ครบ อ่านจบเลือกได้เองทั้งขนาดและ class

ขนาดท่อ PVC เรียกยังไง หน่วยนิ้ว หุน กับ มม.

หน้างานไทยเรียกท่อเป็น "นิ้ว" หรือ "หุน" โดย 1 นิ้ว = 8 หุน ดังนั้น 4 หุนคือครึ่งนิ้ว 6 หุนคือ 3/4 นิ้ว

แต่จุดที่ช่างหลายคนเข้าใจผิดคือ ตัวเลขนิ้วเป็นแค่ "ชื่อขนาด" ที่ใช้เรียกกันเท่านั้น ไม่ใช่เส้นผ่านศูนย์กลางจริงของท่อ

ท่อ PVC ที่เรียกว่า 1/2 นิ้ว ไม่ได้มีเส้นผ่านศูนย์กลาง 12.7 มม. แต่มีเส้นผ่านศูนย์กลางภายนอก (OD) จริงอยู่ที่ 22 มม. ตามมาตรฐาน มอก. เพราะฉะนั้นเวลาซื้อข้อต่อหรือวัดหน้างานต้องยึด OD เป็นหลัก ไม่ใช่ตัวเลขนิ้ว

สรุปคำที่ต้องรู้:

  • OD = เส้นผ่านศูนย์กลางภายนอก ตัวเลขนี้เท่ากันทุก class ในขนาดเดียวกัน ทำให้ข้อต่อใช้ร่วมกันได้
  • ความหนาผนัง = ตัวที่เปลี่ยนตาม class ยิ่ง class สูงผนังยิ่งหนา รูในเลยแคบลง

ตารางขนาดท่อ PVC มาตรฐาน มอก. 17-2561 (นิ้ว ↔ มม.)

ชั้นคุณภาพ (class) ท่อ PVC สีฟ้าคืออะไร

ท่อ PVC สีฟ้าตาม มอก. 17-2561 แบ่งชั้นคุณภาพตามความสามารถในการรับแรงดันน้ำ ตัวเลข class คือ แรงดันใช้งานสูงสุดที่ท่อรับได้ต่อเนื่องที่อุณหภูมิ 27 องศาเซลเซียส หน่วยเป็นบาร์ (bar) หรือ กก./ตร.ซม.

Classแรงดันใช้งานสูงสุดลักษณะผนังเหมาะกับงาน
Class 55 บาร์บางสุดระบายน้ำ น้ำทิ้ง ปล่อยตามแรงโน้มถ่วง งานแรงดันต่ำ
Class 8.58.5 บาร์ปานกลางประปาในบ้าน ระบบมีปั๊มน้ำ งานทั่วไป
Class 13.513.5 บาร์หนาสุดเดินฝังดิน แรงดันสูง งานประปาหลัก งานโครงการ

ในขนาดเรียกเดียวกัน OD จะเท่ากันทุก class แต่ผนังจะหนาต่างกัน เช่น ท่อ 2 นิ้ว OD 60 มม. เท่ากันหมด แต่ผนัง class 5 หนา 1.8 มม. class 8.5 หนา 2.9 มม. และ class 13.5 หนา 4.3 มม. ยิ่งผนังหนา รูในยิ่งแคบ อัตราการไหลก็ลดลงเล็กน้อย ตรงนี้ต้องเผื่อไว้ในงานที่ต้องการปริมาณน้ำมากๆ

หมายเหตุ: ท่อขนาดเล็ก 1/2", 3/4" และ 1" ส่วนใหญ่ผลิตเฉพาะ class 8.5 และ 13.5 ไม่มี class 5 เพราะผนังจะบางเกินไปจนใช้งานไม่ปลอดภัย

ท่อ PVC สีฟ้า กับ สีเทา ต่างกันยังไง

เจอบ่อยมากที่หน้างานหยิบผิดสี เพราะราคาต่างกันแล้วคิดว่าใช้แทนกันได้ จริงๆ คนละหน้าที่กันเลย

  • ท่อสีฟ้า = ท่อประปารับแรงดันตาม มอก. 17-2561 ออกแบบมาให้ทนแรงดันน้ำ ใช้กับน้ำดี ระบบปั๊ม และงานที่มีแรงดันในเส้นท่อ
  • ท่อสีเทา = ท่อร้อยสายไฟ ผนังบาง ไม่ได้ออกแบบมารับแรงดันน้ำ ใช้เดินสายไฟฟ้าในผนังหรือฝ้าเท่านั้น

อย่าเอาท่อสีเทามาเดินประปาแทนสีฟ้าเด็ดขาด เพราะเจอแรงดันปั๊มแล้วมีโอกาสแตกร้าว ส่วนงานร้อยสายไฟก็ควรใช้ท่อสีเทาที่ออกแบบมาโดยเฉพาะ ไม่จำเป็นต้องไปใช้ท่อฟ้าที่หนากว่าและแพงกว่า

เลือกขนาดและ class ยังไงให้เหมาะกับงาน

หลักง่ายๆ ที่ใช้ได้จริงหน้างาน:

งานประปาในบ้าน / ระบบมีปั๊มน้ำ — เลือก class 8.5 เป็นมาตรฐาน รับแรงดันปั๊มได้สบาย ทนแรงกระแทกน้ำ (water hammer) ตอนปั๊มตัดต่อได้ดี ขนาดท่อเมนนิยม 3/4" ถึง 1" ท่อแยกเข้าจุดใช้น้ำ 1/2"

งานเดินฝังดิน / ท่อเมนแรงดันสูง / งานโครงการ — เลือก class 13.5 เพราะผนังหนา ทนแรงกดจากดินและแรงดันในระบบได้ดีกว่า อายุใช้งานยาว คุ้มกว่าในระยะยาว

งานระบายน้ำ / น้ำทิ้ง / ท่อปล่อยตามแรงโน้มถ่วง — class 5 พอ เพราะไม่มีแรงดันในเส้นท่อ ประหยัดต้นทุนได้ นิยมใช้ขนาด 2" ขึ้นไปตามปริมาณน้ำ

งานร้อยสายไฟ — ใช้ท่อสีเทาโดยเฉพาะ ไม่ต้องยึด class ของท่อฟ้า

ถ้าไม่แน่ใจว่าระบบมีแรงดันเท่าไร ให้เลือก class สูงขึ้นหนึ่งขั้นไว้ก่อนปลอดภัยกว่า ต้นทุนต่างกันไม่มากแต่ลดปัญหาท่อแตกซ่อมยากทีหลังได้เยอะ

คำถามที่พบบ่อย (FAQ)

ท่อ PVC class 5 8.5 13.5 ต่างกันยังไง

ตัวเลข class คือแรงดันใช้งานสูงสุดที่ท่อรับได้ที่ 27 องศาเซลเซียส class 5 = 5 บาร์ class 8.5 = 8.5 บาร์ class 13.5 = 13.5 บาร์ ยิ่ง class สูง ผนังยิ่งหนา รับแรงดันได้มากขึ้น

ขนาดท่อ PVC เรียกเป็นนิ้วหรือมิลลิเมตร

เรียกเป็นนิ้วหรือหุนหน้างาน แต่ตัวเลขนิ้วเป็นแค่ชื่อขนาด ไม่ใช่ขนาดจริง ต้องดู OD จากตารางมาตรฐาน มอก. เช่น ท่อ 1/2" มี OD จริง 22 มม.

ท่อ PVC สีฟ้ากับสีเทาต่างกันยังไง

สีฟ้าเป็นท่อประปารับแรงดันตาม มอก. 17-2561 สีเทาเป็นท่อร้อยสายไฟผนังบางไม่รับแรงดัน ห้ามเอาสีเทามาเดินประปาแทนสีฟ้า

งานประปาบ้านทั่วไปควรใช้ท่อ PVC class ไหน

นิยมใช้ class 8.5 เพราะรับแรงดันปั๊มได้พอเหมาะและทนแรงกระแทกน้ำได้ดี ส่วนงานฝังดินหรือแรงดันสูงเลือก class 13.5

ท่อ PVC class 5 ใช้กับงานอะไร

เหมาะกับงานไม่มีแรงดันหรือแรงดันต่ำ เช่น ระบายน้ำ น้ำทิ้ง ปล่อยตามแรงโน้มถ่วง ไม่เหมาะกับระบบปั๊มแรงดันสูง

สรุป เลือกท่อ PVC ให้ครบจบที่เดียว

เลือกขนาดจาก OD ให้ตรงกับข้อต่อ เลือก class จากแรงดันของระบบ แล้วอย่าสลับท่อฟ้ากับเทา แค่นี้งานก็ไม่มีปัญหาย้อนหลัง
